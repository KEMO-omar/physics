# معمل المقذوفات الفيزيائي المتقدم (Physics Projectile Lab)

تطبيق ويب تفاعلي باللغة العربية مبني باستخدام **React 19** و **Vite** و **TypeScript** و **Tailwind CSS** لمحاكاة وحل مسائل حركة المقذوفات في بُعدين، مصمم وفقًا للمنهج المصري للفيزياء للشهادة الثانوية.

## المميزات الرئيسية

- **الأنماط الحسابية المباشرة والعكسية (6 أنماط):**
  1. مسألة مباشرة (معلوم: $V_0$، $\theta$، $h_0$ $\rightarrow$ استنتاج المدى، الزمن، وأقصى ارتفاع).
  2. حساب السرعة الابتدائية ($V_0$) من المدى الأفقي المعلوم ($R$).
  3. حساب السرعة الابتدائية ($V_0$) من أقصى ارتفاع ($H_{max}$).
  4. حساب ارتفاع المبنى ($h_0$) من زمن الهبوط والسرعة الأفقية للقذف الأفقي ($\theta=0^\circ$).
  5. حساب زاوية القذف ($\theta$) من المدى المعلوم.
  6. حساب زمن الهبوط الكلي ($t$).

- **المحاكاة الفيزيائية التفاعلية (HTML5 Canvas 60 FPS):**
  - مسار مكافئ دقيق مع خط استرشادي منقط وخط مسار فعلي مع تقدم المقذوف.
  - إمكانية تشغيل المحاكاة، إيقافها مؤقتًا، واستئنافها، وإعادة المسار.
  - نمط العرض البطيء (Slow Motion 0.3x).
  - تمثيل متجهات السرعة اللحظية ($V_x$ و $V_y$ ومحصلة السرعة $V$) مع أسهم اتجاهية.
  - دعم أشكال مقذوفات متعددة (كرة، قذيفة مدفع، صاروخ، صخرة، عملة نقدية).
  - مؤثرات احتفالية (Confetti) عند هبوط المقذوف على الأرض بنجاح.

- **لوحة القياسات الفورية (Telemetry HUD):**
  - عرض مباشر للزمن المنقضي ($t$)، الارتفاع اللحظي ($y$)، المسافة الأفقية ($x$)، والسرعة اللحظية ($V$).

- **خطوات الحل التفصيلية والمعادلات:**
  - خطوات استنتاجية مرقمة توضح القانون الفيزيائي والتعويض المباشر بالأرقام والوحدات.

- **ملاحق المنهج الثانوي:**
  - تلخيص قوانين المقذوفات الأفقية ومقذوفات الزاوية ومحددات الجاذبية لمختلف الكواكب والأجرام السماوية (الأرض، القمر، المريخ، المشتري، وقيم مخصصة).
